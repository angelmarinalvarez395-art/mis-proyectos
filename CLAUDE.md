# CLAUDE.md — Workspace de Ángel

## Estilo de código (universal)

- Sin comentarios triviales: solo comentar el "por qué", nunca el "qué".
- Consistencia de formato (Prettier o equivalente según el lenguaje).
- Sin código muerto ni dependencias innecesarias.
- Preferir soluciones simples sobre abstracciones prematuras.
- No generar código inseguro (XSS, injection, etc.).
- No añadir librerías externas sin justificación clara.

## Git

- Mensajes de commit en inglés, formato imperativo: `fix: ...`, `feat: ...`, `chore: ...`.
- Un commit por cambio lógico, no por archivo.

## Forma de trabajar

- Respuestas concisas: directo al punto, sin relleno.
- Preguntar antes de tomar decisiones de arquitectura importantes.
- Cada proyecto tiene su propio CLAUDE.md con contexto específico.
